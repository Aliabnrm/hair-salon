# ADR-009 — انتشار بررسی‌شده و مرز کاتالوگ عمومی

تاریخ: ۲۰۲۶-۱۱-۰۲؛ وضعیت: تصمیم اجرایی اسپرینت ۵.

انتشار بخشی از aggregate سالن در salon-management است. state فقط در businesses نگهداری می‌شود. content_revision نسخه همه محتوای قابل انتشار، publication_version نسخه تصمیم انتشار و version نسخه مشخصات سالن است. همه writeها همان سطر سالن را قفل می‌کنند. تغییر محتوا پس از replay و پیش از action، revision را افزایش می‌دهد و published/pending_review را به draft می‌برد؛ rollback همه اثرها را برمی‌گرداند. پاسخ و ETag مشخصات، وضعیت نهایی تراکنش را نشان می‌دهند.

درخواست رضایت مالک، revision، تصمیم و تاریخچه در publication_events ثبت می‌شوند. تأیید فقط به request_id و revision جاری با بررسی دوباره آمادگی و دسترسی reviewer مستقل تعلق دارد. reviewer_permissions حق صریح حساب است؛ اعطا/لغو فقط CLI توسعه/تست با دلیل و تاریخچه دارد. حق درون تراکنش هم بررسی و قفل می‌شود؛ replay حق لغوشده را دور نمی‌زند. تأیید ایمیل شرط انتشار نیست.

تصمیم HTTP شامل content_revision دیده‌شده است و If-Match نسخه منبع انتشار را حمل می‌کند؛ هر دو باید مطابق وضعیت جاری باشند. رویدادها با publication_version یکتای هر سالن مرتب می‌شوند؛ زمان now() آغاز تراکنش است و در رقابت تراکنش‌ها الزاماً ترتیب گرفتن قفل و commit را نشان نمی‌دهد. FK مرکب business_id/request_id اتصال درخواست به همان سالن را تضمین می‌کند.

آمادگی، بازه مشترک پیوسته سالن و متخصص را برای مدت خدمت به‌علاوه بافرها بررسی می‌کند؛ جمع چند بازه جدا کافی نیست. این کنترل آمادگی است و availability یا slot تولید نمی‌کند.

پروفایل با یک SELECT و projection صریح JSON ساخته می‌شود؛ تمام زیرqueryها snapshot همان statement را می‌بینند. صفحه عمومی و preview از همین DTO استفاده می‌کنند و مجوز در سرور مستقل اعمال می‌شود. همه پاسخ‌ها no-store هستند. snapshot موازی عمومی، کش عمومی و موتور جست‌وجوی خارجی نداریم. این انتخاب عمداً پس از ویرایش، نمایش عمومی را تا بررسی مجدد متوقف می‌کند.

جست‌وجوی فارسی روی نام سالن و نام خدمات فعال از تابع immutable مشترک DB برای کلید ذخیره‌شده و ورودی استفاده می‌کند. display اصلی حفظ می‌شود. قیمت «از» کمترین قیمت خدمات دسته انتخاب‌شده است؛ شرط متن جست‌وجو آن را null نمی‌کند. cursor شامل timestamp متنی کامل، UUID و digest فیلتر است؛ ترتیب ایجاد/UUID پایدار است. index بر state/created_at/id برای مسیر منتشرشده است.
