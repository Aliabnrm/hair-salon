# فاصله آیکن در انتخاب‌گرها

این اصلاح با درخواست کارفرما و بر اساس تصویر انتخاب خدمت و متخصص انجام شد؛ اسپرینت تازه‌ای شروع نشده است.

## علت و اصلاح

فلش پیش‌فرض `select` را مرورگر رسم می‌کرد و padding متن، فاصله آن فلش از لبه را تنظیم نمی‌کرد. این الگو در ۸ کنترل از ۶ بخش تکرار شده بود: انتخاب خدمت و متخصص عمومی، ثبت دستی نوبت، متخصص دفتر روزانه، برنامه هفتگی، برنامه روز خاص و دسته خدمت.

`frontend/src/components/ui/select-control.tsx` ظاهر مشترک همین کنترل‌هاست. خود `select` بومی حفظ شده و فقط فلش پیش‌فرض در حالت عادی با آیکن موجود پروژه جایگزین شده است. در اندازه معمول متن، آیکن ۱۶ پیکسل اندازه و ۱۶ پیکسل فاصله از لبه دارد؛ فضای ۴۸ پیکسلی انتهای کنترل، جای آیکن و فاصله ۱۶ پیکسلی آن از متن را محفوظ نگه می‌دارد. متن از لبه مقابل نیز ۱۶ پیکسل فاصله دارد. مقدار طولانی با سه‌نقطه نمایش داده می‌شود و مقدار واقعی انتخاب‌شده حفظ می‌شود.

`ps`، `pe` و `end` جهت منطقی دارند؛ در RTL فلش سمت چپ و در LTR سمت راست قرار می‌گیرد. `containerClassName` فاصله بیرونی، مثل `mt-2`، را روی محفظه می‌گذارد تا مرکز عمودی فلش با خود کادر، مستقل از فاصله برچسب، یکی بماند. ارتفاع و ظاهر قبلی هر کادر از `className` همان مصرف‌کننده می‌آید.

ویژگی‌های اصلی، از جمله `id`، `required`، `disabled`، `value`، `onChange` و `ref` به همان کنترل بومی منتقل می‌شوند. آیکن تزئینی است و کلیک را نمی‌گیرد. در حالت کنتراست اجباری سیستم، فلش بومی برمی‌گردد و آیکن تزئینی پنهان می‌شود.

بررسی عرض ۳۲۰ با متن ۲۰۰ درصد، بیرون‌زدگی دکمه‌های حرکت روزها از کنار عنوان «روز مراجعه» را نیز نشان داد. در `frontend/src/features/availability/components/day-picker.tsx` ردیف عنوان اجازه شکستن به دو خط گرفت؛ در عرض معمول، ترتیب قبلی حفظ می‌شود. دیگر آیکن‌های بازشونده در اطلاعات سالن و انتخاب شهر، فاصله داخلی و فاصله از متن داشتند و تغییر نکردند.

## بررسی واقعی

اندازه‌گیری مرورگر روی صفحه عمومی موجود، در عرض‌های ۳۲۰، ۳۶۰، ۳۹۰ و ۴۳۰، فاصله ۱۶ پیکسلی آیکن از لبه و اختلاف صفر بین مرکز عمودی آیکن و کادر را برای هر دو انتخاب‌گر تأیید کرد. نمایش RTL و LTR، متن طولانی، حالت غیرفعال و کنتراست اجباری نیز بررسی شد. در عرض ۳۲۰ با متن ۲۰۰ درصد، محتوای اصلی اسکرول افقی نداشت. در این بررسی فقط صفحه عمومی خوانده شد و داده سالن تغییر نکرد.

تصاویر و اندازه‌گیری‌های محلی در `work/select-icon-spacing/` قرار دارند و وارد Git نمی‌شوند. وابستگی تازه‌ای نصب یا به پروژه اضافه نشده است.

بررسی نسخه نهایی با Node.js `24.22.2` و pnpm `12.16.1`:

- `pnpm --filter @hair-salon/frontend run typecheck`: موفق.
- `pnpm --filter @hair-salon/frontend run lint`: موفق.
- `pnpm --filter @hair-salon/frontend run format:check`: موفق.
- `pnpm --filter @hair-salon/frontend exec playwright test availability.spec.ts availability-midnight.spec.ts salon-management.spec.ts bookings.spec.ts --max-failures=1`: هر ۲۰ تست موفق، حدود ۱٫۱ دقیقه. اجرا با `PLAYWRIGHT_CHANNEL=chrome` و دیتابیس اختصاصی تست انجام شد؛ fixture نسخه مستقل Next را واقعاً ساخت و رفتار انتخاب، ذخیره و رزرو را بررسی کرد.
- `git diff --check`: موفق.

تست تازه‌ای برای بازگویی کلاس‌های ظاهری اضافه نشده است. بررسی کامل بک‌اند و CI راه‌دور برای این تغییر محلی اجرا نشده‌اند. تغییرها در شاخه `fix/select-icon-spacing` ثبت‌نشده باقی می‌مانند؛ مجوز commit/push درخواست قبلی مربوط به همان سه ادغام بود. پیام پیشنهادی commit:

```text
fix(ui): align dropdown icons and control spacing
```
