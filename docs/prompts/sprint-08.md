# پرامپت اجرایی اسپرینت۸

طرح مصوب [اسپرینت۸](../planning/sprints/sprint-08-plan.md) را کامل اجرا کن. AGENTS.md، ADR-002، استانداردهای backend/frontend و quality-gates مرجع‌اند. Nest Modular Monolith و feature bookings، Next feature/api/hooks/components و Design System موجود را گسترش بده؛ ابزار و پکیج تازه برای این قابلیت لازم نیست.

ابتدا dev را ff-only به‌روز و شاخه مستقل بساز؛ تغییر کارفرما را حفظ کن. هیچ commit/push/PR/merge/deploy انجام نده. برنامه و قانون خالص لغو/جابه‌جایی با ساعت تزریق‌شده، port مشخص، transaction و adapter PostgreSQL جدا باشند. قواعد در UI یا Controller قرار نگیرند. actor و resource را پیش از قفل و replay بررسی کن؛ کلید، نسخه، ظرفیت، snapshot و رویداد در همان transaction هماهنگ باشند. زمان انتظار قفل در بررسی deadline لحاظ شود.

دو ساعت پیش از زمان فعلی مرز شامل است؛ مقصد نیز حداقل دو ساعت آینده و در افق۳۰روز و گام۱۵دقیقه باشد. همان نوبت/خدمت/سالن با قیمت/مدت/بافر توافق‌شده جابه‌جا شود؛ متخصص مجاز جدید ممکن است. موقتاً وقت قبلی را لغو و رزرو دیگری نساز. اگر مقصد پر شد یا سرویس/سالن در دسترس نبود، وقت قبلی تغییر نکند. لغو مشتری به انتشار سالن وابسته نباشد. تاریخچه قدیمی حفظ و migration اعمال‌شده بازنویسی نشود؛ triggerهای تغییرناپذیری و ledger برای جابه‌جایی دقیق گسترش یابند.

صفحه جزئیات مشتری اقدامات و مهلت روشن، تأیید لغو با دلیل و انتخاب زمان جدید با مقایسه قبل/بعد داشته باشد. تاریخچه در جزئیات مشتری/مالک قابل مشاهده باشد. componentها کوچک و معنادار؛ hook برای orchestration و API mapping متمرکز. اجزای انتخاب روز/زمان و Button/Feedback موجود را بازاستفاده کن. در نتیجه مبهم، انتخاب قفل و کلید قبلی حفظ و بررسی نتیجه ممکن باشد؛ PII در URL/storage/log نرود. از موفقیت خوش‌بینانه رزرو استفاده نکن.

unit مرز زمان/ورودی، HTTP auth/CSRF/version، PostgreSQL واقعی race/rollback/constraint/replay/upgrade و مرورگر مشتری→تغییر→همان دفتر مالک و لغو→آزادشدن را اجرا کن. موبایل، RTL، focus، متن بزرگ و خطای شبکه/نتیجه گمشده را بررسی کن. اسناد قرارداد/معماری/ردیابی، گزارش و درس ساده با مثال واقعی را هماهنگ کن و نتیجه واقعی check را ثبت کن. برنامه را محلی آماده تست تحویل بده؛ حساب/رزرو واقعی کارفرما را برای آزمون تغییر نده.
