# منابع طراحی اسپرینت ۴ و حدود شواهد

**وضعیت جاری:** منابع OTPAuth/رمزنگاری عامل دوم در این سند سابقه بررسی اجرای اولیه‌اند؛ پس از درخواست حذف طبق ADR-008، dependency و implementation مرتبط حذف شدند. jalaali-js همچنان استفاده می‌شود.

تاریخ بررسی: ۲۰۲۶-۱۱-۰۱. موضوع این بررسی **تهیه طرح/پرامپت** است؛ هیچ پیاده‌سازی، benchmark، migration یا تست runtime اسپرینت ۴ از آن نتیجه نمی‌شود. انتخاب نسخه dependency جدید در اجرای مصوب و پس از بررسی سازگاری baseline انجام می‌شود.

## شواهد داخلی و تقدم تصمیم‌ها

در زمان آماده‌سازی، کد و اسناد اسپرینت ۳ و pnpm از شاخه `feat/sprint-03-frontend-auth`، commit `b80151c` خوانده شدند. `origin/dev` پس از fetch روی `7360ce9` بود. ساخت مستندات از dev به‌روز، به معنی وجود کد اسپرینت ۳ در آن نیست. گزارش اسپرینت ۳ و ADR-006 شاهد اجرای تاریخی خودشان هستند؛ آزمون تازه این مرحله نیستند.

مرجع تصمیم‌ها: AGENTS جاری کارفرما، ADR-002، ADR-005/006 در baseline اسپرینت ۳، استانداردهای backend/frontend، Git و quality-gates؛ قراردادهای پیشنهادی Business/Staff/Hours و MFA در API/data/security؛ Q-03/04/12/15. ساختار پنل تازه طراحی پیشنهادی است و منبع فیگمای پنل هنوز تأیید نشده است.

## برداشت‌های پروژه و کار باقی‌مانده

تفکیک ۴A/۴B، یک feature با زیرقابلیت‌های روشن، سقف داده/نرخ، assurance هشت‌ساعته و idle سی‌دقیقه‌ای، integer IRR و مدل تک‌متخصص، تصمیم‌های پیشنهادی همین طرح‌اند. این اعداد/انتخاب‌ها از رتبه‌بندی GitHub، vendor یا تأیید قبلی کارفرما نقل نشده‌اند.

در اجرای مصوب، کتابخانه TOTP و در صورت نیاز تبدیل تقویم بر اساس مستند رسمی/نسخه/engine/license بررسی و نتیجه به این فایل اضافه شود. تا آن زمان نام/نسخه‌ای نصب یا سازگاری‌اش قطعی اعلام نمی‌شود. قالب پرامپت از قرارداد موجود `docs/prompts/README.md` پیروی می‌کند؛ در این مرحله ادعای مطالعه تازه راهنمای رسمی Codex یا رتبه‌بندی تازه مخازن نداریم.

## انتخاب‌های بررسی‌شده هنگام اجرای ۲۰۲۶-۱۱-۰۱

بخش‌های بالا سابقه تهیه طرح‌اند. پس از تأیید اجرای کامل، فایل package.json، README و typeهای نسخه واقعاً نصب‌شده بررسی شدند؛ compatibility با اجرای build/typecheck و تست‌های واقعی سنجیده شد، نه با رتبه GitHub.
