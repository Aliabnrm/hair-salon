فایل‌های HTML مطالعه و JSON کامل EXPLAIN زیر `work/sprint-06-*` شاهد محلی ignored هستند؛ credential یا داده توسعه وارد سند نشده است. helperهای Intl/قیمت و الگوی useRemote از کد همین پروژه reuse شده‌اند؛ لایه تازه از مخزن خارجی کپی نشده است.

دریافت HTML صفحه transaction-iso چند بار به timeout/TLS timeout خورد؛ به‌جای ادعای مطالعه آن HTML، منبع رسمی همان مستند از مخزن PostgreSQL خوانده شد. EXPLAIN و Temporal از سایت رسمی دریافت شدند.
